## 1. Executive Editorial Manifesto

A website that sounds like an AI prompt destroys developer trust within three seconds. Phrases like *"unlocking endless possibilities"*, *"redefining the future"*, and *"where innovation meets creativity"* signal that a company has no specific point of view, no real technical depth, and no authentic client history.

**To Inspire** writes like an engineer-founded software studio with a deep cultural anchor:
1. **Verifiable Facts Only**: We never claim nonexistent enterprise clients, fake revenue stats, or artificial user numbers.
2. **Problem-First Precision**: When describing software, we state the exact friction point being solved (e.g. *"Adherence apps treat reminders like alarms, so users mute them; DoseLoop built a calm dose state machine that escalates quietly"*).
3. **Respect for Cultural Heritage**: The Sanskrit creed *"यथा कल्पना तथा रचना"* is treated as a foundational philosophical commitment—what is conceived with intellectual rigor must be constructed with physical integrity.

## 3. Project-by-Project Verified Technical Narratives

### Project 1: ARGUS AI — Industrial Hazard Intelligence
- **Problem Statement**: Harsh factory environments (boiler rooms, machining bays, chemical storage) experience preventable industrial accidents because standard surveillance systems only record video passively instead of triaging active hazards in real time.
- **What Was Built**: An enterprise-grade, edge-native computer vision surveillance platform developed for BPUT Hackathon 2026 (Problem Statement PS06). Detects Fire, Smoke, Restricted Smoking, and Missing PPE (Hardhat/Helmet, Hi-Vis Vest, Gloves, Boots) with sub-second alert latency.
- **Technical Architecture**: YOLOv11s ONNX model optimized via OpenVINO runtime, NestJS 11 WebSocket backend for real-time triage streaming, Next.js 15 App Router frontend, Prisma ORM with SQLite/Postgres persistence, and 100% offline LAN resilience with hardware GPIO siren relay triggers.
- **Inspectable Deliverable**: Repository at `sakashdora/PPE-PROJECT`, complete with architectural diagrams and model benchmark metrics.

### Project 2: TradeVault / RiskRule — Institutional Trading Journal
- **Problem Statement**: Retail traders frequently destroy trading capital not from bad entries, but from emotional "revenge trading" and lack of disciplined position sizing. Existing trade journals merely track retrospective PnL without behavioral context or real-time risk telemetry.
- **What Was Built**: An institutional-grade trading terminal developed in collaboration with AssetMagnets, Bhubaneswar. Integrates automated broker trade synchronization (Dhan, AngelOne), FIFO position aggregation, and an interactive intelligence hub.
- **Technical Architecture**: React + TypeScript frontend with Zustand state store, Recharts dense data visualization, Node.js + PostgreSQL backend, and Lunar AI behavioral discipline coaching powered by Groq and Anthropic LLM pipelines.
- **Inspectable Deliverable**: 63-page technical internship report at `MCA-2025/TradeVault_Internship_Report_Complete.md` and repository at `Pritam-Pattanaik/riskrule`.

### Project 3: DoseLoop — The Calm Medication Companion
- **Problem Statement**: Standard medication reminder applications treat notifications like blaring alarm clocks. Users become desensitized, mute their devices, and abandon adherence.
- **What Was Built**: A privacy-first, calm medication companion for patients managing complex, multi-dose prescriptions. Built around trust, gentle escalation, and small moments of clarity.
- **Technical Architecture**: Custom 4-state dose machine (planned, taken, skipped, missed) driving every viewport without ambiguous UI. Features a granular "Family Circle" caregiver visibility model, hydration and wellness rings, SOS emergency ping, and offline PWA capability.
- **Stack**: React, Vite, Tailwind CSS, TanStack Router, TanStack Query, Radix UI, Supabase / Node.js backend.
- **Inspectable Deliverable**: Live production deployment at `doseloop.vercel.app` and repository at `im-chandanmahapatra/DOSELOOP`.

### Project 4: HarvestIQ — Cryptocurrency Tax Loss Harvesting
- **Problem Statement**: Retail cryptocurrency investors sit on significant realized and unrealized capital losses that could legally offset taxable capital gains, but existing platforms bury the data in disparate CSV exports and complex PDF tax ledgers.
- **What Was Built**: A single-surface portfolio optimization dashboard that ranks harvestable tax opportunities by net dollar impact and calculates cost basis in real time.
- **Technical Architecture**: Next.js with TypeScript, Tailwind CSS, Recharts for dense financial time-series visualization, virtualized tables for large transaction datasets, WebSocket live price feed with REST fallback, and a tokenized color system for tax threshold clarity.
- **Inspectable Deliverable**: Live production application at `harvest-tax-dashboard.vercel.app` and repository at `im-chandanmahapatra/harvestiq-tax-dashboard`.

### Project 5: CrossFire 2026 — Campus Event Operations Engine
- **Problem Statement**: Managing a state-level inter-college talent hunt with thousands of participants across six simultaneous competitive tracks (Quiz, Debate, Poster Making, Treasure Hunt, Ramp Walk, Reels) creates massive bottlenecks at registration desks and scoring tables.
- **What Was Built**: The official event operations platform for Srusti Academy of Graduate Studies (SAGS), Bhubaneswar. Coordinates participant intake, door access validation, judge evaluations, and live leaderboard calculations.
- **Technical Architecture**: React 18.3.1 with TypeScript 5.7.3 and Vite 6.1.0, Supabase for authenticated role-based access control (Admins, Judges, Volunteers), and a real-time cryptographic QR scanning engine for door access validation.
- **Inspectable Deliverable**: Live production platform at `cross-fire-three.vercel.app` and repository at `sakashdora/CrossFire`.

### Project 6: PURE GO — Luxury D2C Hydration Commerce
- **Problem Statement**: Direct-to-consumer beverage product launches require a tactile, high-fashion digital storefront that maintains friction-free checkout performance on mobile devices.
- **What Was Built**: A luxury e-commerce product launch platform featuring fluid Framer Motion product showcases, multi-currency support, cart persistence, and live payment processing.
- **Technical Architecture**: React + TypeScript + Vite, Tailwind CSS, React Query for server state caching, Framer Motion layout transitions, and Razorpay SDK integration for secure checkout.
- **Inspectable Deliverable**: Repository at `im-chandanmahapatra/pure-go`.
