## 4. Audit of the Current Website's Visual Language

### 4.1 Weaknesses Identified in the Previous Architecture
1. **Disconnected Background Composition**: The previous iteration relied on arbitrary floating glowing blobs (`.glow-1`, `.glow-2`, `.glow-3`) with heavy CSS blurs that created visual mush without architectural structure.
2. **SaaS Template Uniformity**: All sections used repetitive rectangular cards with standard rounded corners and 1px borders, eroding the sense of bespoke digital craftsmanship.
3. **Lack of Dual-Theme Art Direction**: The site was locked into a dark-only mode, failing to provide an equally considered light editorial experience.
4. **Generic Copy Residue**: Despite improvements, residual phrases like *"Where Bold Imagination Meets Precision Engineering"* still felt like agency slogans rather than authentic software engineering manifestos.
5. **Shallow Project Telemetry**: Projects were displayed with superficial tags rather than communicating the real problem-solving engineering behind DoseLoop's dose state machine, Argus AI's YOLO edge detection, or TradeVault's FIFO lot accounting.
